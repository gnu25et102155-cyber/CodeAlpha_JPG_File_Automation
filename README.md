# JPG File Automation

## 📌 Internship Task 3

A simple Python automation script that automatically finds JPG files in a folder and moves them into a separate folder.

## 🚀 Features

- Detects JPG files automatically
- Creates a separate folder for JPG files
- Moves JPG files automatically
- Displays the number of files moved
- Reduces repetitive manual file organization

## 🛠️ Technologies Used

- Python
- os module
- shutil module
- File handling
- Loops
- Conditional statements

## ▶️ How to Run

1. Install Python.
2. Open this project in VS Code.
3. Place JPG files in the project folder.
4. Open the terminal.
5. Run:

```bash
py automation.py
